For the end-to-end procedure that binds a qualified Codex build to its exact
binary identity, Atlas policy, native-runtime resolution, sandbox execution,
observed feature boundary, E2E witness, regression gate, and rollback, see:

- [`atlas-runtime-promotion.md`](atlas-runtime-promotion.md)
