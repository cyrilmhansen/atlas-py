# Atlas — Semantic Kernel POC

Experimental branch for testing the minimal semantic kernel of Atlas.

Scope:
- descriptions;
- facts;
- semantic relations;
- alternative realizations;
- resource dependencies and sharing;
- simple specialization.

The implementation is intentionally independent from previous Atlas POCs.

See `knowledge.md` for experimental findings.
